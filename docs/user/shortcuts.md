# Atajos de teclado

Los atajos del lector funcionan con un documento abierto. Las letras no distinguen mayúsculas.

## Navegación

| Atajo | Acción |
|---|---|
| `Flecha derecha` | Página siguiente |
| `Flecha izquierda` | Página anterior |
| `Mayús+Flecha derecha` | Capítulo siguiente |
| `Mayús+Flecha izquierda` | Capítulo anterior |
| `G` | Encender o apagar el avance automático |
| `Flecha abajo` | Párrafo siguiente |
| `Flecha arriba` | Párrafo anterior |
| `I` | Índice |
| `P` | ¿Dónde estoy? |
| `Esc` | Volver |

## Selección y anotaciones

| Atajo | Acción |
|---|---|
| `Mayús+Flecha abajo` | Extender la selección hacia abajo |
| `Mayús+Flecha arriba` | Extender la selección hacia arriba |
| `R` | Resaltar |
| `S` | Subrayar |
| `L` | Dibujar |
| `B` | Poner un marcador |
| `Intro` | Escribir una nota |
| `Ctrl+Intro` | Guardar la nota |
| `C` | Consultar la selección |
| `A` | Panel de anotaciones |

## Lectura

| Atajo | Acción |
|---|---|
| `Ctrl+F` | Buscar en el documento |
| `T` | Ajustes del libro |
| `M` | Modo de lectura |
| `V` | Leer en voz alta |
| `N` | Fondo sonoro |
| `E` | Estudiar con IA |
| `Z` | Lectura inmersiva |
| `F11` | Pantalla completa |
| `+` / `-` | Acercar / alejar |

## Vista dividida

| Atajo | Acción |
|---|---|
| `D` | Dividir la vista |
| `Ctrl+Tab` | Cambiar de mitad |
| `Ctrl+Flecha izquierda` | Estrechar la mitad activa |
| `Ctrl+Flecha derecha` | Ensanchar la mitad activa |
