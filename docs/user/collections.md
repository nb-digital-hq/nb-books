# Colecciones y estanterías

## Estanterías

Las estanterías se crean solas a partir de tus libros: por autor, serie, materia, idioma o año. No tienes que
mantenerlas; aparecen y se actualizan cuando cambia tu biblioteca. Las estanterías vacías no se muestran.

## Colecciones

Las colecciones son tuyas: agrupa los libros como quieras ("Tesis", "Para el verano", "Curso de Historia").

* Crea una colección desde la barra superior de la Biblioteca.
* Añade libros desde la ficha de cada obra.
* Un libro puede estar en varias colecciones.
* Borrar una colección **no borra sus libros**: siguen en tu biblioteca.

## Etiquetas y filtros

Combina filtros (formato, idioma, estado de lectura, colección) para encontrar exactamente lo que buscas. Los
filtros solo ofrecen opciones que llevan a algún resultado.
