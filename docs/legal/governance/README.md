# Gobernanza del Proyecto

> **Estado:** Aplicable.

Quién decide, cómo se decide y cómo se responde ante incidentes. Para un producto que se ofrece también a
instituciones, saber quién sostiene el software y con qué reglas es un requisito de adopción tan real como un
requisito técnico.
