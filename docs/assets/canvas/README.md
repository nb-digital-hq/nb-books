# Fuentes del Canvas de Interfaz

Los archivos `.dc.html` de esta carpeta son las **fuentes** del canvas de diseño de la interfaz, y
`canvas.json` es su disposición. El archivo `nb-books-interfaz.html` es el canvas ya ensamblado.

No son implementación y no entran en la compilación de la aplicación: son el paso previo, igual que el
[prototipo de baja fidelidad](../prototipo-interfaz.html) lo fue para ADR-012. Se editan aquí y se
vuelven a ensamblar; nunca se edita el archivo ensamblado a mano.

| Archivo | Qué es |
|---|---|
| `Inicio.dc.html` | La pantalla de arranque |
| `Main.dc.html` | Biblioteca |
| `Lector.dc.html` | Lector, con el plano del libro y los modos |
| `Estudio.dc.html` | Notas enlazadas y sus retroenlaces |
| `Ajustes.dc.html` | Plano de la aplicación |
| `DireccionPapel.dc.html` | La misma Biblioteca en una paleta clara |
| `DireccionTinta.dc.html` | La misma Biblioteca en una paleta fría |

La dirección principal se llama **Gabinete**: carbón cálido, latón y Literata para la lectura. El acento no es
un color fijo, es un ajuste.
