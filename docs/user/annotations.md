# Anotaciones

## Tipos de anotación

| Qué | Cómo | Atajo |
|---|---|---|
| Resaltar | Selecciona el texto y elige Resaltar | `R` |
| Subrayar | Selecciona el texto y elige Subrayar | `S` |
| Dibujar un trazo | Activa el trazo y marca sobre la página | `L` |
| Escribir una nota | Selecciona el texto y escribe | `Intro`; `Ctrl+Intro` para guardar |
| Poner un marcador | En la posición actual | `B` |

Puedes seleccionar con el ratón o con el teclado: `Mayús+Flecha abajo` / `Mayús+Flecha arriba` extienden la
selección párrafo a párrafo.

## Tus anotaciones no se pierden

Cada anotación se ancla al **texto**, no a un número de página. Por eso sigue en su sitio aunque cambies el tamaño
de letra, la ventana o el modo de lectura, e incluso si vuelves a importar el libro o abres otra edición. Si un
pasaje cambió, la aplicación te avisa en lugar de colocar la nota en el lugar equivocado.

## Verlas y exportarlas

* `A` abre el panel de anotaciones del libro abierto.
* En **Estudio** ves las anotaciones de todos tus libros juntas.
* Puedes **exportar** las anotaciones de un libro a formatos abiertos para usarlas en otras herramientas.
