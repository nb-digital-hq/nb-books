# Accesibilidad

NB Books está pensada para usarse **por completo con el teclado** y con **lector de pantalla**.

## Teclado

Todas las acciones tienen atajo y el foco siempre es visible. Ver [atajos de teclado](shortcuts.md).

## Lectores de pantalla

* Los controles tienen nombres descriptivos.
* `P` ("¿Dónde estoy?") anuncia el capítulo y la posición.
* Los tableros tienen una vista equivalente en lista.

## Visión

* Temas claros, oscuros y de **bajo contraste** como el tema papel, pensado para sesiones largas.
* Tamaño de letra, interlineado y márgenes por libro; acercar y alejar con `+` y `-`.
* **Foco de línea**, que atenúa el resto del texto para seguir la lectura.
* Si tu sistema pide **movimiento reducido**, las animaciones desaparecen.

## Escuchar en lugar de leer

La lectura en voz alta (`V`) funciona con las voces del sistema y con una voz neuronal local, y puede preparar el
audio de libros enteros.
