# Trademark Policy

The Apache License 2.0 grants rights over the code. It does **not** grant rights over names or logos (Apache 2.0,
section 6). This policy explains how the names **"NB"**, **"NB Digital"** and **"NB Books"**, and the associated
logos (the marks), may be used. The Spanish reference is [docs/legal/trademark.md](docs/legal/trademark.md).

## Why

The code may be freely used, modified and redistributed. The marks identify the official distribution, so that
nobody can sell a modified, insecure or abandoned version under the same name to a person or an institution.

## Allowed without permission

* Referring to NB Books by name in articles, tutorials, comparisons and educational material.
* Stating that an extension is "for NB Books" or "compatible with NB Books".
* Using the unmodified logo to link to the official project.
* Redistributing unmodified official binaries, keeping the name.

## Requires written permission

* Using a mark as part of the name of another product, service or extension.
* Distributing a modified version under the name NB Books or NB Digital.
* Suggesting endorsement, affiliation or official certification.
* Using the marks in a third party's commercial material.

## Forks

A fork must change the product name, the application identifier (`lat.nbdigitallabs.books`) and the icon before it is
distributed. Attribution such as "based on NB Books" is welcome.

## Extensions

The extension registry applies this policy: an extension may not be named in a way that suggests it is an official
component. See the [extension policy](docs/legal/governance/extension-policy.md).

## Editions

"Community" designates the open-source suite under Apache 2.0. "Institution" designates the commercially licensed
institutional offering. A self-managed institutional deployment of the open-source application is not an
"Institution" edition.
